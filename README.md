# grade-calculator-java
A simple command-line grade calculator written in Java
The program asks for the number of courses, takes each grade, calculates the average, and shows whether the student passed or failed.
## Features
- User inputs number of courses
- Accepts grades for each course
- Calculates average
- Prints "Passed" if average >= 60, otherwise "Failed"
